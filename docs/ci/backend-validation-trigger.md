# Backend Validation Trigger

این فایل فقط برای فعال‌سازی و ثبت اجرای CI مراحل Backend ایجاد شده است.

Workflow مورد انتظار:

- Composer validation
- Dependency installation
- Migration fresh
- PHPUnit
- Laravel health
- Docker Compose validation

هیچ قانون مالی، رفتار Kimia یا داده عملیاتی را تغییر نمی‌دهد.
